# Riepiloghi delle prime prove

Copie byte per byte dei riepiloghi locali. Provenienza e SHA256 in [inventory.json](inventory.json). Gli originali restano in `artifacts/`, ignorata da Git. Nessuna nuova partita o verifica degli esiti ? stata eseguita per creare queste copie.

Un `report.json` pu? essere intermedio o contenere una verifica finale vuota: leggere fase, tempi e conteggi. I file `progress.json` sono checkpoint, non rapporti finali. I percorsi assoluti nei manifest appartengono alla macchina della sessione originale.

Questa raccolta include i riepiloghi selezionati, non tutte le traiettorie grezze e tutti i checkpoint. I verbali completi delle sessioni manuali sono indicizzati nella [guida](../ESPERIMENTO.md).
